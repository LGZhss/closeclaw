# 提案 034: 并发清理临时文件优化

**状态**: ✅ 已通过（用户特批）
**提出者**: Bolt

## 目标
优化 `src/utils/fs-cleanup.ts` 中的 `cleanupTmpFiles` 函数，通过引入分块的 `Promise.all` 机制，将串行的文件删除操作改为并发执行，从而大幅提高大量临时文件清理场景下的性能。

## 方案
修改 `cleanupTmpFiles`，将遍历 `tempFiles` 的串行 `for` 循环替换为并发处理机制，每次处理 50 个文件，以避免 `EMFILE` 错误。

## 影响
在高负载情况下，临时文件可能积压，串行 I/O 操作会阻塞事件循环并延长整体执行时间。并发执行能有效缩短清理操作的总体耗时。
