## 🛠️ 2. 修改说明

### 2.1 变更目标

目前 `src/adapters/registry.ts` 中的 `LLMAdapterRegistry` 类缺乏单元测试。为了提高代码库的可靠性并确保适配器管理的正确性，我们需要为其编写全面的单元测试。

### 2.2 核心逻辑

- 使用 Vitest 框架。
- 模拟 `src/logger.ts` 以验证日志行为。
- 测试以下方法：
  - `register`: 验证适配器注册及重复注册时的覆盖逻辑。
  - `get`: 验证适配器获取及不存在时的错误抛出。
  - `has`: 验证适配器存在性检查。
  - `list`: 验证返回所有已注册适配器名称。
  - `unregister`: 验证适配器移除逻辑。
  - `clear`: 验证清空所有适配器。
  - `size`: 验证适配器数量统计。
