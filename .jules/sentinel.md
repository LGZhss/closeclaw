## 2026-04-13 - Path Traversal Bypass via String Prefix Matching

**Vulnerability:** `resolveSafePath` used `targetPath.startsWith(absoluteBase)` to check for path traversal. This allows bypassing the check if the target directory is a sibling directory that shares the same prefix name as the base directory (e.g., base `/workspace/project`, target `/workspace/project-secrets`). Additionally, protected path checks were performed on the raw user input, allowing bypasses like `src/../../project/.env`.
**Learning:** String-based `.startsWith()` matching on paths is vulnerable to prefix collision bypasses. Input paths must also be fully resolved to verify they fall correctly within the intended base boundary.
**Prevention:** Always fully resolve both paths (`path.resolve()`), compute the relative path (`path.relative(base, target)`), and verify the relative result does not start with `..` and is not absolute (`!path.isAbsolute(relativeResult)`). Protected path checks should be run against this normalized relative path.
